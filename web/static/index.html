GlimRegion — Halcon Region Features 재현 로컬 대시보드

폴더 단위로 이미지를 검사하여 Halcon 13 Region Features(면적/원형도/진원도/이방성 등)를 OpenCV 로 재현·산출하고, 프로파일 기반 Score/분류 결과를 시각화합니다. 계산은 C++ 엔진(GlimRegionBatch.exe)이 수행하며, 웹은 결과 표시 전용입니다.

  1. 설정 탭에서 폴더 경로·프로파일·이진화 방식을 정하고 미리보기로 확인
  2. 분석 실행 시 결과 탭에서 카드 갤러리로 Region 별 특징/오버레이 확인
  3. 분석 탭에서 불량 분포·Score·특징값 히스토그램 확인
